Pruebas de Hipótesis para Varianzas

Chi-cuadrada para una varianza · F de Fisher para dos varianzas

Prueba χ² para H₀: σ² = σ₀²
χ² = (n−1)S² / σ₀² con ν = n−1 grados de libertad.
Intervalo de confianza: [(n−1)S²/χ²_{α/2} , (n−1)S²/χ²_{1−α/2}]

Prueba F para H₀: σ₁² = σ₂²
F = S₁² / S₂² con ν₁ = n₁−1 y ν₂ = n₂−1 grados de libertad.
Convenio: coloca la muestra con mayor S² en el numerador (F ≥ 1).

Pruebas de Hipótesis para Proporciones

Prueba Z para una o dos proporciones · Intervalos de confianza (Wald y Wilson)

Prueba Z para H₀: p = p₀
z = (p̂ − p₀) / √(p₀q₀/n)
IC de Wald: p̂ ± z_{α/2}√(p̂q̂/n)  ·  IC de Wilson (más preciso para n pequeño o p extrema).
